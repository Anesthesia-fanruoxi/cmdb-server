# SQL规则检查接口使用说明

## 接口信息

- **路径**: `POST /api/sql/rules/check`
- **功能**: 检查SQL语句是否符合配置的规则
- **依赖**: 
  - SQL分析接口 (`analyze.AnalyzeMultiSQL`)
  - 数据库规则表 (`sql_rule`)

## 请求示例

```bash
POST /api/sql/rules/check
Content-Type: application/json

{
  "sql": "CREATE TABLE test (id INT)"
}
```

## 工作流程

1. **接收请求** - 解析JSON请求体，获取SQL语句
2. **分析SQL** - 调用 `analyze.AnalyzeMultiSQL()` 获取完整的解析结果
3. **加载规则** - 根据SQL类型（CREATE/ALTER/UPDATE等）从数据库加载启用的规则
4. **执行检查** - 使用 `CheckRuleEngine()` 对每条规则进行检查
5. **返回结果** - 返回详细的检查结果和汇总信息

## 核心特点

- ✅ **独立功能** - 不影响其他模块，只依赖SQL分析和数据库
- ✅ **支持批量** - 可以一次检查多条SQL语句
- ✅ **配置驱动** - 规则完全由数据库配置，无需修改代码
- ✅ **详细结果** - 返回每条规则的检查结果和完整的SQL分析结果
- ✅ **分类清晰** - 规则分为安全类(security)和规范类(standard)

## 初始化

执行以下SQL脚本初始化规则数据：

```bash
mysql -u root -p cmdb < script/sql_rule_new.sql
```

默认会创建20条规则，其中10条默认启用。

## 管理规则

### 查询规则列表

```bash
GET /api/sql/rules/list
```

### 启用/禁用规则

```bash
PUT /api/sql/rules/update?id=1
Content-Type: application/json

{
  "is_enabled": 1  // 1-启用, 0-禁用
}
```
