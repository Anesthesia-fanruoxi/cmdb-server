# 插件安装参数说明

## 📋 概述

插件安装时根据**插件类型**传递不同的参数给Agent。

---

## 🔧 参数传递规则

### **1. 容器类型 (container)**

#### 传递给Agent的参数：
```json
{
  "name": "sql-plugs",
  "version": "2.0",
  "category": "container",
  "image": "hub.hzbxhd.com/test/sql-plugs:2.0",        // ✅ 镜像地址（必传）
  "download_url": "http://192.168.3.12/sql-plugs",    // ✅ 下载地址（必传）
  "port": 8080,                                        // ✅ 宿主机映射端口（必传）
  "config": {                                          // ✅ 环境变量配置（可选）
    "DB_HOST": "localhost",
    "DB_PORT": "3306"
  },
  "parameters": {
    "container_port": 80                               // ✅ 容器内端口（可选）
  }
}
```

#### 字段说明：
| 字段 | 来源 | 说明 |
|-----|------|------|
| `image` | 动态拼接 | `{image_url}/{name}:{version}` |
| `download_url` | 动态拼接 | `{download_url}/{name}` |
| `port` | 前端传入 | 宿主机映射端口，必须传递 |
| `config` | 前端传入 | 环境变量配置，可选 |
| `parameters.container_port` | 数据库字段 | 容器内端口，来自`t_plugin_store.port` |

---

### **2. 二进制类型 (binary)**

#### 传递给Agent的参数：
```json
{
  "name": "mysql-client",
  "version": "1.0",
  "category": "binary",
  "download_url": "http://192.168.3.12/mysql-client",  // ✅ 下载地址（必传）
  "command": "./mysql-client --host=localhost"         // ✅ 启动命令（可选）
}
```

#### 字段说明：
| 字段 | 来源 | 说明 |
|-----|------|------|
| `download_url` | 动态拼接 | `{download_url}/{name}` |
| `command` | 前端传入 | 启动命令，用户安装时自定义 |

---

## 📊 参数对比表

| 参数 | container | binary | 说明 |
|-----|-----------|--------|------|
| `name` | ✅ | ✅ | 插件名称 |
| `version` | ✅ | ✅ | 版本号 |
| `category` | ✅ | ✅ | 插件类型 |
| `download_url` | ✅ | ✅ | **所有类型都传递** |
| `image` | ✅ | ❌ | 仅container |
| `port` | ✅ | ❌ | 仅container |
| `config` | ✅ | ❌ | 仅container |
| `parameters` | ✅ | ❌ | 仅container |
| `command` | ❌ | ✅ | 仅binary |

---

## 🗄️ 数据库字段

### `agent_store` 表结构：

```sql
CREATE TABLE `agent_store` (
  `id` bigint PRIMARY KEY COMMENT '主键ID',
  `name` varchar(64) NOT NULL COMMENT '插件名称',
  `version` varchar(32) NOT NULL COMMENT '版本号',
  `display_name` varchar(128) NOT NULL COMMENT '显示名称',
  `plugin_type` varchar(32) NOT NULL COMMENT '插件类型(container/binary)',
  `description` text COMMENT '插件描述',
  `port` int DEFAULT 0 COMMENT '插件服务端口(容器内端口,仅container类型)',
  `created_at` datetime COMMENT '创建时间',
  `updated_at` datetime COMMENT '更新时间'
);
```

**注意：** `command` 字段**不存储在数据库**中，仅在安装时由前端动态传递。

## 📝 配置文件

### `config/config.yaml` - Agent配置：

```yaml
agent:
  image_url: "hub.hzbxhd.com/test"           # 容器镜像仓库地址
  download_url: "http://192.168.3.12/plugs"  # 下载基础地址
```

## 🔄 完整流程示例

### **容器类型插件安装：**

1. **前端请求：**
```json
POST /api/agent/store/install
{
  "plugin_id": 1,
  "project": "test-project",
  "container_port": 8080,
  "config": {
    "DB_HOST": "localhost"
  }
}
```

2. **从数据库查询插件：**
```json
{
  "id": 1,
  "name": "sql-plugs",
  "version": "2.0",
  "plugin_type": "container",
  "port": 80
}
```

3. **构建并发送给Agent：**
```json
POST {agent_url}/api/plugins/install
{
  "name": "sql-plugs",
  "version": "2.0",
  "category": "container",
  "image": "hub.hzbxhd.com/test/sql-plugs:2.0",
  "download_url": "http://192.168.3.12/plugs/sql-plugs",
  "port": 8080,
  "config": {
    "DB_HOST": "localhost"
  },
  "parameters": {
    "container_port": 80
  }
}
```

---

### **二进制类型插件安装：**

1. **前端请求：**
```json
POST /api/agent/store/install
{
  "plugin_id": 2,
  "project": "test-project"
}
```

2. **从数据库查询插件：**
```json
{
  "id": 2,
  "name": "mysql-client",
  "version": "1.0",
  "plugin_type": "binary"
}
```

3. **构建并发送给Agent：**
```json
POST {agent_url}/api/plugins/install
{
  "name": "mysql-client",
  "version": "1.0",
  "category": "binary",
  "download_url": "http://192.168.3.12/plugs/mysql-client",
  "command": "./mysql-client --host=localhost"
}
```

---

## ⚠️ 注意事项

1. **download_url所有类型都传递**
   - 容器类型可能需要下载配置文件等
   - 二进制类型需要下载可执行文件

2. **container_port必填校验**
   - 容器类型必须传递 `container_port`
   - 二进制类型不需要端口

3. **config仅容器类型支持**
   - 用于传递环境变量
   - 二进制类型不传递此字段

4. **command仅由前端传递**
   - 不存储在数据库中
   - 用户安装时可自定义启动参数
   - 如果前端不传，则不会传递给Agent
