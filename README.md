# CMDB 运维管理平台

基于 Go 语言开发的运维管理平台后端服务，面向研发和运维团队，提供 SQL 管控、日志检索、资产管理、监控告警、知识库、作业平台等核心能力，通过 Agent 插件机制对接各类基础设施。

---

## 技术栈

- **语言**：Go 1.25，使用原生 `net/http` 构建 HTTP 服务，无第三方 Web 框架
- **数据库**：MySQL 8.0，使用 GORM v2 作为 ORM
- **缓存**：Redis 7.0，用于 Token 存储、查询缓存、任务状态、SSE 推送等
- **认证**：JWT，支持 PC 端和移动端双 Token 体系，Token 存储于 Redis 支持主动失效
- **权限**：基于 RBAC 的接口级权限控制，每个接口绑定具体权限标识
- **密码安全**：SHA256 + bcrypt 双重加密，密码复杂度规则可在系统设置中动态配置
- **通知**：支持邮件（SMTP）和飞书（卡片消息、长连接 WebSocket）两种通知渠道
- **日志**：Zap 结构化日志
- **配置**：YAML 配置文件，通过 Viper 加载

---

## 功能模块

### SQL 管控

提供面向研发的 SQL 全生命周期管控能力。

- **SQL 查询**：通过 Agent 代理执行 SQL，支持分页查询、查询历史、取消正在执行的查询、结果导出，以及对结果中手机号字段的自动解密脱敏
- **SQL 审批**：SQL 变更工单流程，提交人发起工单，经审批人审批后由执行人执行，支持飞书卡片消息审批回调
- **SQL 导出审批**：大数据量导出工单，执行后自动生成 Excel 文件并通过邮件发送，支持临时下载链接
- **SQL 流程配置**：配置审批人和执行人的流程模板，供工单创建时选择
- **SQL 规则引擎**：可配置的 SQL 审查规则，在工单提交时自动检查，支持正则匹配、关键词检测、条件判断、表名限制、WHERE 条件强制等多种规则类型
- **SQL 分析**：对 DDL、DML、DQL 语句进行结构解析，提取表名、字段、索引、操作类型等信息
- **共享查询**：保存和共享常用 SQL，团队成员可直接复用
- **DataBI**：基于 Spark 的大数据查询能力，支持 SSE 实时推送表列表、异步导出、字段注释管理

### 日志检索

统一的日志检索入口，对接多种日志存储后端。

- **Elasticsearch 检索**：支持全文检索、聚合分析、上下文查询、滚动查询、数据导出
- **阿里云 SLS 检索**：对接阿里云日志服务，支持查询和分析
- **Manticore Search 检索**：对接 Manticore Search 引擎
- **检索视图**：保存常用的检索条件和字段配置，支持团队共享
- **共享关键词**：团队共享的检索关键词，快速复用常用过滤条件

### 资产管理

管理基础设施资产，提供操作入口。

- **K8s 管理**：查看 Pod 状态、Service 列表和 Namespace 信息
- **项目发版**：发版任务的创建和管理，支持 WebSocket 实时日志推送和移动端 SSE 推送
- **域名管理**：对接阿里云 DNS，支持解析记录的增删改查
- **密钥管理**：数据加解密服务，支持批量解密，操作全程审计
- **文件管理**：服务器文件目录浏览和文件上传
- **阿里云余额**：账户余额查询和 ECS 实例到期监控

### 监控告警

对接 Prometheus 和 VictoriaMetrics 的监控数据查询能力。

- **指标查询**：支持即时查询、范围查询，以及通过 SSE 批量推送多个指标的实时数据
- **监控视图**：自定义监控面板，保存常用的指标组合和图表配置
- **告警管理**：查看当前触发的告警列表

### 知识库

团队文档管理系统，支持多种文档类型和协作场景。

- **项目文档**：按项目组织的私有文档，支持历史版本记录和版本回滚
- **公共文档**：团队共享文档，支持分享链接、匿名访问、多格式下载（Markdown、Word、PDF）
- **个人空间**：个人私有文档，独立于项目文档
- **回收站**：已删除文档的暂存和恢复

### 作业平台

脚本任务的统一调度和执行管理。

- **任务管理**：脚本任务的创建、编辑、删除，支持 Cron 表达式定时调度
- **任务绑定**：将任务绑定到具体项目并配置执行参数
- **执行记录**：任务执行历史查询和详情查看
- **调度器控制**：运行时动态启动、停止、重载任务调度
- **Agent 上报**：Agent 执行完成后回调上报结果

### Agent 插件管理

通过 Agent 插件机制对接各类基础设施，实现统一的代理访问。

- **插件管理**：插件的注册、版本管理、配置模板预览
- **插件商店**：用户侧的插件浏览和一键安装
- **项目插件**：按项目维度管理已安装的插件，支持启动、停止、重启、卸载、版本升级、配置更新，以及 WebSocket 实时日志

### 审计

全面的操作审计能力，满足合规要求。

- **操作日志**：用户的所有操作记录
- **登录日志**：登录历史和登录来源
- **SQL 审计**：SQL 查询记录，支持按用户统计分析和查询明细
- **ES 审计**：Elasticsearch 检索记录，支持用户维度统计
- **加解密审计**：密钥操作的完整记录
- **IP 审计**：IP 位置查询记录

### 系统管理

平台基础配置和权限管理。

- **用户管理**：用户 CRUD、启用/禁用、密码重置、角色和部门分配
- **角色管理**：角色 CRUD、菜单权限分配
- **部门管理**：树形部门结构、项目关联
- **菜单管理**：菜单树、路由配置、权限标识配置
- **字典管理**：系统字典数据维护
- **系统设置**：密码策略（长度、复杂度）、登录保护（失败次数限制、锁定时间）、Token 有效期
- **Redis 管理**：Redis 数据浏览、Key 查询和删除

### 任务中心

异步任务的统一管理入口，聚合各模块产生的后台任务。

- 任务列表查询、数据预览、取消任务、结果导出、临时下载链接生成
- K8s Pod 扩缩容任务

---

## 安全机制

- 密码采用 SHA256 + bcrypt 双重加密存储
- JWT Token 存储于 Redis，支持主动失效和多端隔离
- 登录失败次数限制，超限自动锁定账号，锁定时间可配置
- 密码复杂度规则（长度、数字、字母、大小写、特殊字符）可在系统设置中动态调整
- 飞书回调等外部接口通过 IP 白名单验证
- 所有业务接口均需 JWT 认证，并通过 RBAC 进行接口级权限校验
